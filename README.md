# qvnote.com

Source of the QVeeNote website. Static HTML; served from Wix hosting, with images referenced from this repository.

- `index.html` — home page
- `beta.html` — how to join the closed beta
- `privacy.html` — privacy policy (also linked from the app and the Play listing)
- `support.html` — support and contact
- `assets/` — stylesheet, logo mark and screenshots

Deploy: push the HTML to the Wix headless site (Claude does this from the session); images load from `raw.githubusercontent.com/OctarineBlu/qvnote-site/main/assets/`.
